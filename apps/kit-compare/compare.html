Exactly what runs

For each pinned version: getTransactionDecoder().decode(bytes), followed by getCompiledTransactionMessageDecoder().decode(transaction.messageBytes). The second call matters: decoding an envelope alone can produce a different result. ACCEPT means both calls returned; it does not mean the transaction is valid or safe.

The JavaScript files are unmodified, self-hosted production browser builds of @solana/kit. The downloadable report records input bytes, SHA-256, versions, API composition and the freshly observed results. It is unsigned. It does not verify transaction signatures, simulate execution, evaluate freshness or assess impact.

Examples are synthetic retained research inputs, not fetched chain transactions. A disagreement is an observed behavior difference to investigate—not automatically a bug, exploit or new discovery. This browser comparison is separate from the existing saved-case Replay service.
