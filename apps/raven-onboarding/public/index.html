Scope & limits
Comparison and Conformance produce unsigned reports. A match is not a safety verdict, and a difference is not a vulnerability claim. The pinned Kit adapters each call the transaction decoder and compiled-message decoder; adapter composition can change outcomes.
Agent Trust verifies a retained signed receipt using the existing pinned verifier. The exchange record you save is unsigned. PROCEED is Agent A’s policy decision, not permission to transact. Nothing here submits a transaction, acquires fresh chain data or moves funds.
These are separate examples. A comparison report is not converted into a receipt. Existing engines, fixtures, profiles, trust configuration and agent policy are retained. This candidate is local only and awaits non-author review.
