Saved regression cases

Save an answer.
Rerun it. See what changed.

A saved case keeps the input bytes, the pinned tool and runtime identity, and the expected result, from Raven’s bundled read-only inspector or from a registered SDK adapter. Rerunning it checks whether the same tool, runtime and policy still produce that result.

MATCH means the saved expectation reproduced. It never means the transaction is safe. An expected parser REJECT can MATCH.

No transaction is sent. Cases live only in this browser tab until you export them, and a case file includes the transaction bytes you supplied: use synthetic or public, non-sensitive input for anything you share.
