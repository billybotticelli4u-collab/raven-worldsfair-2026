Operator Console

The learning loop: lead asks → signed receipt goes back → role/decision/gaps tracked → usage repeats or dies → next build chosen from measured evidence. Everything here is template + script; real data lives in private/ (gitignored).

Surfaces

  • Leads — full-field tracker (render private/leads.json)
  • Dot plot — who comes back (30-day grid)
  • Evals · Receipts · Feedback classifier
  • Decisions — human approval log · Skills — operator playbooks

Daily loop (≈10 min)

1. node scripts/generate-raven-daily-brief.mjs — health, evals, follow-ups, recommendation.
2. New lead? add to private/leads.json → classify (raven-feedback-classifier.mjs) → reply from templates/ (verdict first).
3. Any key/beta/public-claim action → log in decisions, Glen approves (policy).
4. Before push: node scripts/raven-change-review.mjs.
