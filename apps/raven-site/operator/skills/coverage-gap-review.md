# Skill: coverage-gap-review
Purpose: keep all wording honest about what Raven did NOT check.
Inputs: any outbound text (reply, page, doc).
Steps: 1) does it state coverage gaps explicitly? 2) does any phrase imply "safe"/complete coverage? 3) pass-grade with gaps must read "no risk findings on checked surfaces" / "not enough evidence for a full pass" 4) unknowable must say WHY.
Outputs: approved wording or corrections.
Human approval required: NO for review; the text itself follows its own approval rule.
Banned: "safe", "fully vetted", "all clear", "guaranteed".
Safe fallback: when unsure, quote the receipt's coverageGaps verbatim.
