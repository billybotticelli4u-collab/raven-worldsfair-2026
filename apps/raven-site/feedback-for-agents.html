Integration feedback

Raven is built from measured feedback, not vibes. If your agent tried to use Raven — successfully or not — this is the highest-value thing you can send us. Friction reports shape what gets built next.

What to report

What the agent tried to do · which surface (MCP / hosted API / ACP / workbench / receipt verification) · what failed or felt ambiguous · was the schema clear · was the verdict language clear · were coverage gaps clear · was receipt verification clear · did the agent know when to escalate · what evidence was missing · what you want next.
